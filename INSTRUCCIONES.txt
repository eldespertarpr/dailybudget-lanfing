SOLUCIÓN A IMÁGENES ROTAS

Este paquete usa un index.html AUTO-CONTENIDO.
Las imágenes están incrustadas dentro del mismo archivo.

Qué subir:
- index.html

No necesitas subir carpeta assets.

Pasos:
1. En GitHub, abre el repo del landing.
2. Sube este index.html reemplazando el actual.
3. Commit: Corregir landing con imágenes incrustadas.
4. Espera 1 minuto y abre la página publicada.

Ventaja:
- Evita errores de carpeta assets/.
- Evita imágenes rotas por nombres o rutas.
